# Wallpaper collection

This folder contains the wallpapers bundled with the macOS Web project.

## Classic Mac OS X / macOS source collection

The original Apple-era wallpapers referenced by the project are from the 512 Pixels wallpaper archive. The archive provides the full historical collection, including Cheetah/Puma through Catalina, plus newer macOS releases.

Source: https://512pixels.net/projects/default-mac-wallpapers-in-5k/

The archive documents these classic releases:

- Mac OS X 10.0 Cheetah
- Mac OS X 10.1 Puma
- Mac OS X 10.2 Jaguar
- Mac OS X 10.3 Panther
- Mac OS X 10.4 Tiger
- Mac OS X 10.5 Leopard
- Mac OS X 10.6 Snow Leopard
- Mac OS X 10.7 Lion
- OS X 10.8 Mountain Lion
- OS X 10.9 Mavericks
- OS X 10.10 Yosemite
- OS X 10.11 El Capitan
- macOS 10.12 Sierra
- macOS 10.13 High Sierra
- macOS 10.14 Mojave — Day / Night
- macOS 10.15 Catalina — Day / Night

The same archive also contains Big Sur, Monterey, Ventura, Sonoma, Sequoia, Tahoe, and Golden Gate.

## Redistribution note

The original Apple wallpapers are copyrighted assets. The public repository does not bundle third-party copies here. The application configuration points to the original source collection instead of redistributing those files directly.
